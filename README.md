# Devora Network (working title)

Developer-first AI and software ecosystem. **Nonproduction research and engineering project.**

## Mission
Help developers earn compensation for verified work and obtain practical startup support through independently reviewed milestones, customer-funded assignments, sponsorships, and compute credits.

## Non-negotiable boundaries
- No public token issuance, ICO, presale, exchange listing, staking yield, or investment-return representations.
- No assumption that a token called a "utility token" is legally a non-security.
- No transfer-fee burn or inaccessible-fee mechanism in the initial design.
- No real funds, wallet credentials, or secrets in this repository.
- No deployment, spending, or merge without explicit founder authorization and independent review.
- $200 USD aggregate spending ceiling; $0 currently committed.
- Provisional name and ticker only; brand/trademark clearance pending.
- Prefer actual customer or sponsor funds for developer payments; tokens do not themselves create grant capital.

## Governance
Feature branch -> tests and security review -> independent verification -> founder approval -> authorized merge/release. Production and mainnet: HOLD.

## Initial milestone
A locally runnable, mock-data-only developer contribution and grant application prototype, with explicit audit records and tests. Future Solana integration is Devnet-only until separately authorized.

## Repository status
This initial charter is a bootstrap commit on main because the repository was empty and had no commit from which to branch. All implementation work belongs on a feature branch.
